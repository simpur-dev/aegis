## 需要留意的四条许可边界

1. **GPL/AGPL 只在"服务端"这一侧**：PostGIS 是 GPL-2.0-or-later、MinIO 与 Neo4j 社区版是
   AGPL-3.0/GPL-3.0，都作为独立服务端进程被调用，不随本平台应用代码分发，因此不产生传染；
   但 AGPL 的第 13 条对"通过网络提供服务"的部署方仍生效——一旦把 MinIO 纳成交付物的一部分，
   就要按交付边界重新评估，而不是沿用今天这句"不传染"。
2. **双许可件要写明取哪一种**：Eclipse Zenoh 的 Apache-2.0/EPL-2.0 双授按 Apache-2.0 使用；
   `orjson` 元数据同时列 Apache/MIT/MPL，按 MIT 使用。这类"多选一"要每次核对上游措辞。
3. **模型权重与代码分开计**：bge-m3（MIT）与 bge-reranker-v2-m3（Apache-2.0）的许可证随权重走，
   由 `scripts/fetch_retrieval_models.py` 落盘并记 sha256；重量级权重不进镜像、不进 git。
4. **检索引擎可换，接口不变**：seekdb（Apache-2.0）作为独立进程经 MySQL 协议被调用，
   应用侧只依赖 `pymysql`（MIT）；换掉或关掉它，两条腿回到"pgvector + 进程内 BM25"，
   内核与 API 语义都不变——这条边界由 `retrieval/port.py` 的索引端口守，而不是靠约定。
